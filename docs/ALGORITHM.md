# 字形保真、尺寸和双向位置

## 1. 可恢复的物理量

原始 PNG 为 1 位图，四周有 10 像素白边，未做尺寸归一。按来源记录恢复每一面栏距 p、版框高 h、原始页面坐标、PDF 内嵌扫描尺寸及放置矩阵。扫描尺寸除以 PDF 中英寸尺寸得到 DPI，实际约 300。

三种量分开保存：

- 原始墨迹像素高宽：可精确重读；裁切清理可能改变紧包围框。
- PDF 物理尺寸：像素 × 25.4 / DPI；这是文件元数据指定的尺寸，不能单独证明印本真实毫米。
- 版框估计：像素 × 193 / h 毫米，193来自书格记载的半叶框高；扫描畸变、书页弯曲及记载近似导致误差，不能称为校准尺测量。

字体主尺度采用 s0=1000/p。同一字的横纵坐标使用同一个尺度，不沿两个轴分别拉伸。原始比例、笔画粗细对比和缺笔均受保护。

## 2. 有界视觉大小校准

测量二值墨量 A、墨迹质心 μ、二阶矩半径 R=sqrt(E|x−μ|²)、骨架上距离变换的中位笔画宽 t，以及复杂度代理 C=A/t²。这些量并不等价：质心是一阶矩，R为二阶矩，骨架中心和外框中心另存。

对 log(R/p) 做 Huber IRLS 稳健回归，自变量为 log C、其平方、绝对 log 高宽比、其平方和交互项。用复杂度和天然高宽比条件化，不把「一」「丨」「鬱」强制同墨量或同外框。

log(s/s0)=clip(0.18×半径回归残差 + 0.12×log(全体中位 t/p ÷ 当前 t/p), log0.92,log1.08)。单字最多约±8%，另有整体墨框不超过0.93em的安全收缩，全部列明。权重是保守设计参数，不是由人类偏好拟合。

## 3. 方向对称的光学位置

继承旧希腊 BD 项目的多尺度墨色场和有限开口深度，结合梵文项目的真实墨迹与有界移动原则。本版是针对汉字固定方框的重新实现，不调用旧希腊数字矩阵。

构造三个尺度（0.018p、0.04p、0.08p）的高斯墨色场，经过饱和映射 1−exp(−density/0.35)，减少单条粗笔画的支配。再取其二维中心；另取墨迹质心、骨架中心、外框中心。

对横、竖轴均提取面对轮廓，开口回缩深度限于0.13p；按每行墨量平方根加权，温度0.04p的log-sum-exp构造两侧软包络中心。深的内白不全部当作字间留白。

用所有中心相对外框中心的加权偏差最小化平移能量：

E(δ)=Σ_j w_j ||s(c_j−c_box)+δ||²。

先验由外框中心项（0.45）约束，墨迹0.12、骨架0.06、三场0.10/0.08/0.06、有限包络0.13。无约束最优解是负加权偏差均值；投影到每轴±0.035em与实际贝塞尔曲线极值距边至少0.0305em的交集（额外0.0005em留给CFF量化），得到凸二次问题的精确解。

输出只是等比缩放及XY平移，写进常规轮廓；横、竖advance均1000，不随上下文改变字距，因此不会造成汉字网格逐字漂移。不能保证任意两字外轮廓恰好同齐；天然疏密与异体差异本就存在。几何代理下降不是阅读舒适度改善百分比。

## 4. SVG 与 CFF

Potrace 1.16，turdsize=0，不额外丢弃微小黑块或孔；初始alphamax=1.0、opttolerance=0.2源像素。每个字以FreeType独立回栅格，比较IoU与墨量。IoU<0.965或墨量误差>2.5%时尝试0.08/0.65的较保守参数，只有IoU改善才采用。若仍低于0.95，再尝试0.02/0.0，以减少细笔画损失；仅在IoU改善时采用。保留最终误差；不把阈值当作已满足所有美学或拓扑要求。

CFF保存三次贝塞尔，免去强制转二次曲线的额外节点。编译量化约1/1000em，SVG坐标保留0.01字体单位。SVG为源文件档案，字体不嵌入庞大的SVG表；网页用无损WOFF2压缩。

不加自动hinting，不增加填孔、平滑、补笔和现代轮廓替换。扫描中的细白点可能增加曲线数量，这是保真与体积的真实成本。

## 5. 验证范围

逐字源哈希、数量、cmap、横竖advance、字体回读、轮廓范围、裁切风险、源分辨率IoU、全表无损压缩检查、全字栅格载入与重点字多字号检查。浏览器实际加载校勘页与横竖排样张。本轮复核清单已由用户于2026-11-08确认完成校对；自动几何检查与人工结论独立保存。部分字形仍残有划痕笔画，未做进一步清理。

本版未声称完成所有字对的心理视觉优化；未制造约22亿字对的GPOS表。既有希腊BD的像素相位损失没有作为汉字拟合项原封移植，小字号通过独立渲染验收。
