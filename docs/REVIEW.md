# 原页重新拉框

运行 `python scripts/serve_review.py --pdf-root 原PDF目录`，打开本地校勘台。默认先看两处位置推定；也可筛选低相似度、补全、清理或搜索字符。

1. 点“重新拉字框”。
2. 在原页拖动矩形框住完整字形；可放大、定位原框。
3. 点“预览净字”，必要时调整二值化阈值。
4. 确认没有漏笔画或夹入邻字，点“保存字图修订”。
5. 重建字体：`python scripts/build.py --workers 8`。

修订保存到 `sources/overrides/`。刷新后仍显示修订 PNG；字体栏显示最近一次构建结果，所以保存后需要重建字体才会同步。可撤销当前修订，历史仍保留。重复出处按字符共用修订；最后一次保存生效。玄与缺笔𤣥共用轮廓，其字框修订也应指向同一目标。

新切图从原PDF最大内嵌扫描取得，框坐标使用原页像素。局部背景归一化后用 Otsu 或手动阈值二值化，收紧墨框，补10像素白边。不填孔、不删部件；框内杂字和框线需人工避开。

逐字缓存键包括源PNG哈希、栏距、测量/描摹函数及参数。只重描发生改变的字图，全部字体仍重新拟合尺寸、定位并编译。
